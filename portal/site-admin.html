Event cards

One card per event, shown in this order while rush is open. Put the date, place, time and dress code in the second line so people can read it without opening the picture.

Pictures are downloaded only while rush is open, by everyone who opens the rush page, and that counts against the free database plan (10 GB a month). When rush closes, switch to closed, set the next semester and save. Visitors then download no pictures, so you can leave them here for next semester. Do not use "Clear everything saved here" to close rush: it also removes the interest-form link and the next semester.
