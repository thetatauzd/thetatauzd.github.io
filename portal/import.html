Copy the Tracker sheet into the site

The Tracker sheet is the record this semester. This copies it into the site so officers can preview the Chapter Ops pages. The sheet itself never changes. Each refresh replaces the whole copy for the term, so rows that were deleted or fixed on the sheet are deleted or fixed here too. A refresh also runs on its own when an admin opens a preview page and the copy is more than a day old.

It takes about half a minute. Brothers keep seeing My Tracker, which reads the sheet directly, so nothing they see changes.
